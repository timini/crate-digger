## Implemented locally

Tauri dependency. Core still has no new networking dependencies.

New modules:

- `credentials.rs`: closed credential enum for LLM, Discogs, YouTube, Soulseek
  username/password and external slskd API key; `SecretStore` trait and native
  `Keychain` implementation. Pins keyring 3.6.3 with Apple, Windows and Linux
  Secret Service features. Uses fixed error text rather than native errors that
  might expose account details. Secrets are not returned to the UI.
- `http.rs`: injectable synchronous transport, bounded 2 MB responses, 90-second
  timeout, redirects disabled, fixed service errors, Retry-After parsing.
  Endpoint validation rejects embedded credentials, query strings and fragments;
  plaintext HTTP is accepted only on loopback. Tests cover endpoint rejection
  and service error redaction. Request intentionally does not implement Debug.

  unknown fields. Discovery defaults disabled; external slskd defaults off.
